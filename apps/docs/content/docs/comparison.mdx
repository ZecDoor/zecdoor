---
title: Compared with CipherSwap and Zodl
description: Other ways to move Solana ZEC into shielded Zcash, described as fairly as we can.
---

Moving Solana ZEC to shielded Zcash in one step is not new. Two tools already do it, and if one of them suits you, use it.

| | ZecDoor | CipherSwap | Zodl (built-in swap) |
|---|---|---|---|
| Where | Web page, opens inside Phantom | Web app | Zodl wallet app (iOS 3.12+, Android 3.15+) |
| Solana deposit | One Phantom signature | One Phantom signature | Manual deposit from another wallet |
| Fee on Solana ZEC moves | 0.25% | 0.5% | 0.67% observed on mainnet |
| Balances below the bridge minimum | Top-up in the same transaction | No | No |
| First Zcash wallet | Made in the page, with a checked backup | No | Zodl is the wallet |
| Destination check | Decodes the unified address; requires an Orchard receiver | Checks the prefix and length | n/a (own wallet) |
| Proof of arrival | Signed quote, both txids, note found by your browser | No shielded-note check | The wallet's own balance |
| Source | MIT licence | Public code, no licence file | Public code (github.com/zodl-inc); licence not checked by us |

Sources for each row are on the [sources page](/sources#rivals). If you already use Zodl, its swap may be all you need.
