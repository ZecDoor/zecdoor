# ZecDoor

Move the ZEC you hold on Solana into your own shielded Zcash wallet.

ZecDoor is open-source, non-custodial software. It is under construction and not ready to use.

## Status

| Part | State |
|---|---|
| `deploy/first-deploy` | Static page with a connect-only Phantom button (no signing code) |
| App, landing page, docs | Not started |
